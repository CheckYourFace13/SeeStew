# SeeStew search growth plan

Goal: shift traffic from branded “SeeStew” queries toward **story and topic** searches (weird American history, forgotten disasters, scandals, military near-misses).

This plan does **not** invent rankings, traffic numbers, or fake credentials. Ideas below are research targets — each needs real sources before publishing.

---

## 1. Top current content gaps

| Gap | Why it matters for search | Suggested fix |
|---|---|---|
| **Revolution hub is thin (1 story)** | High intent (“Boston Massacre,” “Whiskey Rebellion,” founding-era oddities) with little internal linking | Publish 4–6 Revolution pieces; cross-link Politics/Military |
| **Presidents hub has zero articles** | Hub copy exists but must stay hidden until content exists | Only add when 2+ sourced presidential episodes ship |
| **Cluster depth uneven** | Weird America is large; Scandal/Crime/Politics need denser internal graphs | Prefer new stories that link to 2+ existing articles |
| **SERP still brand-heavy** | Titles/meta improved, but Google needs more topic/query matches | Target under-covered event names + “what happened” phrasing |
| **Shorts ↔ article pairing incomplete** | Shorts can seed curiosity; articles must catch the search | Every new story needs a Shorts angle in the brief |
| **Local / regional disasters underused** | Strong “near me” / place-name search (cities, states, rivers) | Prioritize named places in titles and hubs |
| **Public-health & workplace disasters** | Evergreen + school/curriculum adjacent | Cutter-style, Triangle-adjacent, mine/mill stories |
| **Cold War accidents / secrecy** | High click for “almost nuclear war” / “cover-up” intents | Keep claims inside declassified records only |

### Editorial rules for every new piece
- Surprising **and** true; refuse unverifiable folklore  
- Named sources only (archives, museums, .gov/.edu, established news)  
- Shorts hook planned before publish  
- At least 2 internal links to existing SeeStew stories/topics  
- `seoTitle` 45–65 chars; `seoDescription` 135–160 chars; run `npm run check:seo-snippets`
